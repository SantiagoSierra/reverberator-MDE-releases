# Reverberator .Wav

[![Última Versión](https://img.shields.io/github/v/release/SantiagoSierra/reverberator-MDE-releases?color=blue&label=Descargar%20%C3%9Altima%20Versi%C3%B3n)](https://github.com/SantiagoSierra/reverberator-MDE-releases/releases/latest)

> **Aplicación ligera para el procesamiento y control de reverberación en tiempo real.**

Simplifica al máximo el uso de la reverberación en tiempo real para sesiones de canto improvisado, locuciones rápidas de video o instrumentos conectados a través de simuladores de cabina (CabSim en amplificadores).

---

## 🚀 Características Principales

* **Procesamiento en Tiempo Real:** Aplica reverberación con baja latencia sobre la señal capturada.
* **Soporte de Archivos Audio:** Diseñado específicamente para el manejo y procesamiento de archivos tipo `.wav`.
* **Selección de Entrada:** Permite seleccionar y grabar directamente desde cualquier línea de entrada conectada al sistema.
* **Sin Complicaciones:** Interfaz ágil y orientada a la practicidad sin configuraciones complejas.

---

## 📦 Instalación y Uso

1. Descarga el archivo `.zip` desde la sección de **Releases**.
2. **Recomendación:** Descomprime el contenido del `.zip` dentro de una carpeta nueva de tu preferencia.
3. Ejecuta el archivo instalador o ejecutable principal (`.exe`).

---

## 🛠️ Requisitos del Sistema y Compatibilidad

* **Archivos soportados:** Audio no comprimido en formato `.wav`.
* **Entradas de audio:** Tarjetas de interfaz, micrófonos o procesadores de guitarra/bajo mediante CabSim.
